About

I got really interested in QR codes and wanted to mess with them, but existing qr code generators weren't flexible enough for me so I wrote my own.

It's not the fastest or best written out there but it has some features I think are neat, so I threw together a website!

It all runs in browser via webassembly so nothing gets uploaded anywhere.

How does the image thing work?

When there's extra space in a QR code after the data, the standard expects you to pad it with a standardized byte sequence, but it turns out nobody actually checks for that.

This gave me the idea to specifically craft a padding sequence to produce an image, and that's what this is!

Put more technically, for each bit in the padding sequence, the final position in the matrix is determined, and the value at that point in the image is XORed with the mask pattern.

Image tips

  • It's best to scale the image down a bit before uploading, QR codes only get up to 177x177 so any bigger than that will require downscaling no matter what.
  • High contrast images work best.
  • Transparency renders as solid black, sorry.
  • If the luminance threshold doesn't produce a good result, try messing around in image editing software. You can obtain better results by prescaling the image and reducing it to 1-bit color with dithering.
  • QR code readers tend to dislike solid black areas.
